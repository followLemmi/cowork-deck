The floating pill

always on top · its own window

It counts only the sessions blocked on a decision. A session that merely finished its turn announces itself with a notification instead — parking at the prompt when it is done is not the same as being unable to continue, and a pill that counted both would be lit permanently.

Session states

Five states and one deliberate absence. Done is the same green as Working without the breathing, because the work finished and nothing is happening — and Ended has no hue at all: it is the absence of a signal, not a signal. Each chip pairs its colour with its own fill, and each is measured; a translucent fill drags the ground towards the text, so the alphas differ by hue rather than being one number applied five times.

Buttons and fields

One primary per screen. Hover moves the ground and never the ink: the old set muted its icon buttons with opacity: 0.7, which composited the panel into the glyph and put every icon control in the app at 2.67:1 while sitting still. Disabled is the only state allowed to lose contrast.

Nothing to show

Four different shapes, because they are four different situations: no data yet, data that has not arrived, a source that cannot be read, and a source that is fine but empty. Collapsing them into one grey box is how "it is broken" and "you have not set it up" become indistinguishable.

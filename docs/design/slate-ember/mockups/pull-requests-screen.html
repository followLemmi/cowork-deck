What this is

A column beside the pull request list that shows one file's patch at a time. It squeezes the list rather than covering it, because a drawer over a list whose rows are still focusable fails SC 2.4.11.

Decisions worth arguing with

  • The pane is sized in ch, not pixels or percent. The one question a diff pane answers is "does this line fit", and that is a column count — so it must not shrink when the text-size control grows.
  • Colour is the third channel for added and removed, not the channel. The two bands measure 1.03 against each other, so the literal + and − live in a column of their own.
  • The band starts at the marker column, never at the frame: on the tint the line-number gutter fell to 4.16, and the gutter has to stay opaque anyway or position: sticky shows the scrolling code through it.

Not in this branch

Word-level highlighting inside a changed line, and a side-by-side mode. Both want a real diff algorithm on the client; this reads the patch GitHub already produced.
